# Guía de evaluaciones y entregables

## 1. Pre-entregable del reporte del proyecto

- [ ] **Análisis de situación**
  - [ ] Sustento del problema
  - [ ] Entorno
  - [ ] Benchmark / competencia
  - [ ] Usuarios
  - [ ] Canvas de negocio

- [ ] **Definición de la hipótesis**
  - [ ] How Might We
  - [ ] Definición del nicho
  - [ ] Definición del problema
  - [ ] Definición de la solución / Point of View

- [ ] **Desarrollo de la marca**
  - [ ] Visión
  - [ ] Misión
  - [ ] Valores
  - [ ] Círculo Dorado

- [ ] **Kit de marca**
  - [ ] Justificación de las definiciones
  - [ ] Moodboard
  - [ ] Colores
  - [ ] Tipografía
  - [ ] Logo
  - [ ] Elementos gráficos
    - [ ] Imágenes
    - [ ] Ilustraciones
    - [ ] Mockups
  - [ ] Definición de la voz de la marca
  - [ ] Definición del tono de la marca

- [ ] **CJM y plan de campaña**
  - [ ] Objetivos
  - [ ] Público
  - [ ] Acciones
  - [ ] Mensajes
  - [ ] Medios / canales
  - [ ] Timeline

- [ ] **Storytelling**
  - [ ] Desarrollo de una historia
  - [ ] Definir cómo será utilizada como uno de los mensajes
